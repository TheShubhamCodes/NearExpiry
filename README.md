# NearExpiry

NearExpiry is an inventory and product expiry-date management application for supermarket and grocery store owners.

## Tech Stack
- **Frontend:** React.js, Vite, Tailwind CSS, React Router, Axios, Recharts, Lucide React
- **Backend:** Node.js, Express.js, Mongoose, JWT, bcryptjs, Zod
- **Database:** MongoDB (Local or Atlas)

## Project Structure
```
NearExpiry/
  client/       # React + Vite frontend
  server/       # Node.js + Express backend
  .gitignore
  README.md
```

## Getting Started

### 1. Prerequisites
- Node.js (v18+)
- MongoDB running locally or a MongoDB Atlas connection string

### 2. Backend Setup
```bash
cd server
npm install
cp .env.example .env
npm run dev
```

### 3. Frontend Setup
```bash
cd client
npm install
cp .env.example .env
npm run dev
```
